# DataCanvas · 可视化 Pandas 工作台

> 用可视化的方式重实现 pandas 的数据分析流程：加载 → 概览 → 清洗 → 分析 → 可视化 → 导出。
> 中文 / English 双语，界面文案由同一份词典驱动，两种语言内容严格一致。

---

## 一、快速开始

环境要求：Node.js ≥ 20（开发时使用 Node 24）。

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://127.0.0.1:4173
npm run build      # 生产构建（先 tsc 严格类型检查，再输出到 dist/）
npm run preview    # 预览生产构建
npm test           # 运行单元测试（vitest）
npm run test:watch # 测试监听模式
```

构建产物是纯静态文件（`dist/`），任何静态服务器都可以托管，无需后端：

```bash
npx serve dist
# 或
python -m http.server 8080 --directory dist
```

## 二、核心设计：一切皆流水线（pipeline）

应用不直接修改数据，而是把用户的每一次操作记录成一条**可复现的操作流水线**：

```
原始数据 (source)
   │  + 筛选 Category 包含 Electronics
   │  + 用中位数填充 Rating
   │  + 按 Category 分组求和 Sales
   ▼
当前结果 (frame)  ──►  概览 / 表格 / 图表 / 导出
```

- 原始数据永远不变，因此撤销、重做、调整顺序都是安全的；
- 流水线的每一步都可以**临时停用**，立即看到该步骤的影响；
- 整条流水线在**后台 Worker 线程**中执行，未变化的前缀步骤复用中间结果（增量缓存）；
- 某一步骤出错会被**单步隔离**：出错步高亮、后续步阻断，结果停留在最后一个有效帧；
- 每一步都会生成对应的 pandas 代码，可一键导出为 `.py` 脚本。

## 四、功能清单

### 数据加载
- CSV / XLSX / XLS / JSON / 项目工程文件（.datacanvas.json），点击选择或拖拽，上限 20MB
- CSV 在独立 Web Worker 中后台解析，大文件不阻塞界面
- 内置 243 行 × 15 列零售示例数据（含缺失值与重复行）
- **默认数据集**：导入时可勾选“记住为我的默认数据集”，存于 IndexedDB，下次启动自动加载
- 启动加载优先级：上次会话 > 默认数据集 > 内置示例
- 自动字段类型识别：数值 / 文本 / 日期 / 布尔

### 清洗与转换（30+ 操作）
| 分组 | 操作 |
| --- | --- |
| 筛选排序 | 15 种判断符、多条件且/或组合、多键升降序排序 |
| 缺失值 | 均值 / 中位数 / 众数 / 零 / 固定值 / 前向 / 后向 / 线性插值填充；按任一或全部为空删行 |
| 重复值 | 整行或指定字段子集去重 |
| 字段工具 | 保留、删除、重命名、类型转换、删除常量列、转置、重置索引、前 N 行、随机抽样 |
| 计算字段 | 类 Excel 公式引擎（`Sales - Cost`、`[Unit Price] * Quantity`） |
| 数值运算 | 累计求和/最大/最小/乘积、变化率、平移、5 种排名、滚动窗口、截断、等频分箱 |
| 文本日期 | 大小写、去空格、长度、子串、查找替换（正则）、匹配标记、拆分、拼接；年月日季度星期周次、日期差 |
| 重塑合并 | 透视表、交叉表（4 种归一化）、melt、四种连接、纵向追加、describe、corr |

### 统计分析
- **一键 Auto EDA**：自动汇总质量变化、缺失率、IQR 异常值、清洗前后差异与相关性
- **分组聚合**：多字段复合分组，12 种聚合函数，实时柱状图 + 合计行
- **数据透视表**：行列值三维配置
- **交叉表**：计数 / 按行 / 按列 / 按总体归一化
- **相关性**：皮尔逊与斯皮尔曼，热力图矩阵 + 最强关联排行
- **相关性钻取**：点击热力图单元格打开对应散点图、回归线与 R²
- **描述性统计**：14 项统计量 + 分布卡片
- **异常值闭环**：IQR / Z-score、阈值调整、异常明细、删除 / Winsorize / 中位数替换、处理前后箱线图与 pandas 代码

### 时间序列分析中心
- 日 / 周 / 月 / 季度自动聚合与日期范围筛选
- 移动平均、环比、同比、累计值与多维趋势拆分
- 最高点、最低点、异常波动与日期断层自动识别
- **Rosling 式时间轴竞速动画**：柱状竞速（逐期自动重排名）与气泡竞速（X/Y/大小三指标联动），
  自动循环播放、三档速度，低基数维度智能默认选中

### 可视化故事板
- 图表一键固定、拖拽排序、中英文结论说明
- 全局分类与时间筛选器联动所有图表
- **点击联动筛选**：点击任意卡片中的图表元素（柱、扇区、树图块……），该类别即成为
  看板级筛选条件，全部图表实时联动收窄；再次点击或一键清除
- **演示模式**：全屏深色放映，8 秒自动轮播，`←` / `→` 翻页、`空格` 暂停、`Esc` 退出，
  注释以大字幕呈现，可直接替代答辩 PPT
- 导出完整仪表盘 PNG，或打印 / 保存 PDF

### 可视化（19 种图表）
柱状图、分组柱状图、堆叠柱状图、折线图、面积图、环形图、散点图、气泡图、
直方图、箱线图、热力图、雷达图、矩形树图、漏斗图、仪表盘、
桑基图、旭日图、平行坐标图、散点矩阵（SPLOM）——覆盖对比 / 趋势 / 占比 / 分布 /
关系 / 层级 / 流向 / 高维全数据形态。

分析增强：
- 根据字段类型、基数和可用度量动态推荐图表，不依赖示例数据字段名
- 散点图自动标注**拟合方程与 R²**
- 图表**框选联动**：拖动框选数据点 → 只保留 / 排除选中数据，图形即筛选器
- 点击柱形、饼图扇区或散点可查看对应原始记录，并可将钻取结果加入流水线
- 切换图表类型时**自动修正字段映射**，避免空白图表
- 图表与统计量同屏呈现（求和、样本数、变化率、极值等）

### 导出
- 数据：CSV / Excel（.xls）/ JSON
- 代码：完整 pandas 脚本（.py），逐行注释对应界面操作
- 工程：`.datacanvas.json` 项目文件（数据 + 流水线 + 故事板），可在任何机器上重新导入继续工作
- **分析报告**：一键导出自包含 HTML——质量评分、字段画像表、10 张离屏渲染图表快照
  （直方图 / 频次条形 / 相关性热力图，2× 清晰度 base64 内嵌）、最强相关对、
  IQR 异常值扫描表、完整 pandas 复现代码；中英双语、白底打印友好，双击即可离线打开

### 工作区持久化
- 数据、流水线、故事板自动防抖保存到 IndexedDB，刷新或关闭后重开自动恢复上次会话
- 语言与主题偏好存于 localStorage，首帧渲染前应用主题，无亮暗闪烁

### 深色模式
- 顶栏一键切换亮 / 暗主题，全站设计变量与 ECharts 图表主题同步切换
- 偏好持久化记忆，刷新后保持

### 稳定性
- **流水线后台计算**：整条流水线在专用 Web Worker 中执行，主线程只负责渲染，大数据量下界面不卡顿
- **增量缓存**：未变化的流水线前缀步骤复用中间结果，追加 / 修改步骤时无需从头重算
- **单步错误隔离**：某一步骤出错不会拖垮整条流水线——出错步高亮、后续步标记阻断，结果停留在最后一个有效帧
- **全局错误边界**：任何未捕获异常显示崩溃卡片，可一键重载或清空会话安全重启

## 五、双语一致性如何保证

`src/i18n.ts` 中以英文键集为唯一标准：

```ts
const en = { rows: 'Rows', columns: 'Columns', /* … */ }
export type MessageKey = keyof typeof en
const zh: Record<MessageKey, string> = { rows: '行数', columns: '字段数', /* … */ }
```

中文词典被声明为英文键集的**完整映射**。若中文漏写或多写任何一个键，
`tsc` 会直接编译报错。因此两种语言不可能不一致——这是编译期强制的，而非人工核对。

## 七、实现说明

- **框架**：React 19 + TypeScript（strict）+ Vite（rolldown）
- **图表**：Apache ECharts（`echarts-for-react`，按需注册）
- **数据解析**：PapaParse（CSV，专用 Worker 线程）、read-excel-file（Excel）
- **后台计算**：两个 Vite 原生模块 Worker——`csvWorker`（解析）与 `pipelineWorker`（流水线执行 + 增量缓存常驻）
- **持久化**：localStorage（语言 / 主题偏好）+ IndexedDB（工作区数据，支持 20MB 级数据集）
- **测试**：vitest，25 项单元测试覆盖统计原语、公式引擎、流水线增量缓存与错误隔离、工程文件解析
- **图标**：lucide-react
- **字体**：Inter + JetBrains Mono 本地打包（`@fontsource`），断网环境可用
- **无后端**：全部计算在浏览器内存中完成，数据不出本机

统计计算全部由项目自行实现（`src/analysis.ts`、`src/utils.ts`），未依赖第三方数据分析库，
以便精确控制计算语义，例如：

- 标准差使用样本标准差（`ddof = 1`），与 pandas `.std()` 默认行为一致
- 分位数采用线性插值，与 `numpy.percentile` 一致
- 排序时缺失值始终排在末尾，与 pandas 一致
- 排除常量列后再计算相关系数，避免除零

## 八、已知边界

- 数据在内存中全量处理，建议单表规模在数万行以内以保证交互流畅
- Excel 导出为 Excel 可直接打开的表格格式（`.xls`），未写入多工作表与单元格样式
- 数据连接需要额外上传一份右侧数据表，且两侧连接键需字段名对应
